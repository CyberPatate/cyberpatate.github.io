## [1.0.0] - 2026-11-18

Initial release.

### Features

- In-cockpit EFB for the Laminar A330-600, ToLiss aircrafts, Aerobask Diamond DA42NG and Airfoillabs Cessna 172 Digital.
- Popup window EFB available for other aircrafts.
- Remote EFB available to display it on an external tablet or browser.
- Up to 8 applications available depending on the aircraft:
  - Simbrief OFP: download and consult all OFP details directly in the EFB
  - Weather: show weather map along the planned route
  - Takeoff and Landing performance calculators for Airbus aircrafts
  - Weight & Balance: manually configure load and fuel, with a seatmap view for Airbus aircrafts
  - Charts: display Navigraph charts in the EFB
  - Checklists: in-cockpit dynamic checklists
  - Browser: integrated EFB browser
